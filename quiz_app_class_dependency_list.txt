クイズアプリ クラス図に近い依存関係一覧

前提
- presentationはReactの関数コンポーネントとhooksで構成する
- applicationはUseCaseクラスで構成する
- domainはEntity / ValueObject / DomainService / Repository Interfaceで構成する
- infrastructureはRepository実装、API通信、S3取得、DynamoDB取得、AppSync Events、localStorageを扱う
- 業務ルールの最終判定はバックエンドが持つ
- フロントは画面制御、整流、依存隠蔽を主目的とする

==================================================
1. 全体の依存方向
==================================================

presentation(function component / hook)
    ↓
application(usecase)
    ↓
domain(entity / service / repository interface)
    ↑
infrastructure(repository impl / api / storage / realtime)

原則:
- presentationはdomainを直接触らない
- presentationはapplicationを経由して業務処理を行う
- applicationはdomainの型とrepository interfaceに依存する
- infrastructureはdomain.repositoriesを実装する
- domainは外側の層を知らない

4. domain内の依存
==================================================

4-1. Entity → ValueObject
関係:
- Room は RoomId, QuestionIndex, RoomStatus に依存
- Participant は ParticipantId に依存
- Question は QuestionIndex, Choice, Score に依存
- Answer は ParticipantId, QuestionIndex, Choice, Score に依存
- Tally は Choice に依存
- ParticipantScore は ParticipantId, Score に依存
- Session は SessionToken, RoomId に依存

--------------------------------------------------

4-2. DomainService → Entity / ValueObject
関係:
- AnswerPolicy は Room, Answer, QuestionIndex に依存
- ScoringService は Question, Answer, Score に依存
- RankingService は ParticipantScore, Score に依存
- SessionPolicy は Session に依存

--------------------------------------------------

4-3. UseCase → DomainService
関係:
- SubmitAnswerUseCase → AnswerPolicy
- ShowResultUseCase → ScoringService
- GetRankingUseCase → RankingService
- ValidateSessionUseCase → SessionPolicy

==================================================
9. 実装時のルール
==================================================

- presentation層はrepositoryを直接呼ばない
- presentation層はentityを直接newしない
- usecaseはUI stateを持たない
- repository実装はentityを返す
- mapperは変換だけに責務を限定する
- localStorageアクセスはLocalStorageServiceまたはSessionStorageGateway経由に限定する
- AppSync Eventsのpublish / subscribe詳細はAppSyncEventsClientに閉じ込める
- 業務ルール判定はif文をpagesに散らさず、domain serviceまたはentityに寄せる
